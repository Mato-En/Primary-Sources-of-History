# Does the Code of Hammurabi Support the Claim That Ancient Babylonian Society was a Patriarchy?
The Code of Hammurabi is a legal text which contains the judgments spoken by King Hammurabi of Babylon, which were then written down. It concerns criminal offences like stealing and violence but also covers family issues like marriage, as well as economic issues like malpractice and pricing.

The following citations are taken from the translation by L. W. King available on the [Avalon Project](https://avalon.law.yale.edu/ancient/hamframe.asp).
